## D. 本番反映の確認方法（次セッションでも同じ手順を使うこと）

<known-fact>
### D-1. 記事・ガイドページ（サーバー側で生成）


### D-2. 料金表（操作で切り替わる部分）は HTML に出ない

`src/components/sections/Pricing.tsx` は操作で切り替わる部品で、
初期表示は「個人向け」タブのため、**法人プランの内容は HTML に含まれない。**
HTML を grep しても新旧どちらも0件になり、判定できない。

### D-3.【重要】配信ファイルは日本語が符号化されているため、そのままでは grep できない

当セッションで、配信ファイルを素の grep で調べたところ
**新旧どちらの文言も0件**になった。これは「削除された証拠」ではなく
**「探し方が間違っている証拠」**である。

正しい手順は、`\uXXXX` を復号してから数えること。
さらに、**必ず対照（残っているはずの文言）を同時に数え、方法が機能していることを確認する。**

```bash
cd /tmp && rm -rf chunkchk && mkdir chunkchk && cd chunkchk
curl -s https://sns-share.com/ | grep -oE '/_next/static/chunks/[^"]+\.js' | sort -u > urls.txt
i=0; while read -r u; do i=$((i+1)); curl -s "https://sns-share.com$u" -o "c$i.js"; done < urls.txt
python3 - <<'PY'
import glob, re
def dec(s):
    return re.sub(r'\\u([0-9a-fA-F]{4})', lambda m: chr(int(m.group(1),16)), s)
txt = "".join(dec(open(f, encoding="utf-8", errors="replace").read()) for f in glob.glob("c*.js"))
for s in ["消えているべき文言", "残っているはずの対照文言"]:
    print(f"{s}: {txt.count(s)}件")
PY
```

この方法で、7項目が本番から消えていること、および
残るべき項目（人数3件・共通4機能・1名あたり6件）が正しい数で存在することを確認済み。
</known-fact>
